# DevOps Toolkit

A shared collection of tools, scripts, queries, CLI commands, and troubleshooting solutions used by the DevOps team to simplify daily operations and share knowledge.

## Repository Structure

| Directory | Contents |
|---|---|
| `scripts/` | Automation scripts (Bash, Python). |
| `queries/` | SQL, monitoring, logging, and infrastructure queries. |
| `cli/` | Useful CLI commands and examples (AWS, kubectl, Docker, Linux). |
| `troubleshooting/` | Diagnostic commands and troubleshooting solutions. |

## Usage

Each tool or solution is maintained as a separate file in its relevant directory.

Check the corresponding directory to find existing resources or add new ones.

## Notes

- Keep tools and examples reusable whenever possible.
- Do not commit credentials, secrets, or sensitive production data.
- Include comments or usage instructions where necessary.
